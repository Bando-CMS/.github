## About

Bando is an open-source, self-hosted headless CMS built with TypeScript.

We're building Bando in the open — from the core and database layer to the API, Studio, client SDKs, and developer tooling.

Our goal is simple: **give developers control over their content, infrastructure, and code.**

## Why Bando?

* **Open source** — inspect, modify, and contribute to the code.
* **Self-hosted** — run Bando on your own infrastructure.
* **TypeScript-first** — designed for modern TypeScript applications.
* **Developer-focused** — simple APIs and a familiar development experience.
* **Composable** — integrate Bando into your existing stack.
* **Built in public** — development happens openly with the community.

## What we're building

```text
Bando
├── Core
├── Database
├── Server
├── Client
├── Studio
└── CLI
```

Each part is designed to work together while remaining flexible enough to integrate with different applications and infrastructures.

## Built in public

Bando is being built openly and with the community.

You can contribute by:

* Opening issues
* Reporting bugs
* Submitting pull requests
* Improving documentation
* Testing new features
* Sharing ideas and feedback

Whether you're interested in the architecture, TypeScript, APIs, databases, developer tooling, or simply want to help shape an open-source CMS, you're welcome here.

## Status

> 🚧 **Early development**

Bando is currently under active development and is **not production-ready yet**.

APIs, packages, and features may change as the project evolves.
